# translateAI v1.0.0 — Windows x64 免安装版

本地 AI 翻译。选中文字按 `Ctrl+P`，译文出现在鼠标旁边。全部在本机推理，不联网。

## 下载

`translateAI-win64-v1.0.0.zip`（约 1.05 GB，**已内置模型**）

解压到任意目录，双击 `translateAI.exe` 即可使用，无需安装、无需 .NET 运行时
（Windows 10 1903+ / Windows 11 自带 .NET Framework 4.8）。

## 功能

- **划词翻译**：任意程序中选中文字 → `Ctrl+P` → 悬浮窗显示译文
- **悬浮窗可选中复制**：`Esc` 或点击别处关闭，长文本自动出现滚动条
- **主窗口**：长文本翻译、14 种常用语言、一键反转方向、多行保留换行
- **免安装**：拷到 U 盘、换台电脑解压即用
- **自动选后端**：有显卡走 Vulkan（NVIDIA / AMD / Intel），没有就退回 CPU
- **模型可换**：把任意 `.gguf` 丢进 `models\`，在设置里切换
- **热键可改**：设置里点一下直接按组合键
- **中英双语界面**：右上角一键切换
- **托盘常驻**：关窗口不退出

## 内置模型

`Hy-MT2-1.8B-IQ4_NL.gguf`（腾讯混元，Apache-2.0，约 1.03 GB）

- 33 种语言互译，中英方向表现最好
- NVIDIA 显卡：约 0.3 秒/句；纯 CPU：约 1–3 秒/句

想换更小/更大的模型：把 `.gguf` 放进 `models\`，在「设置」里选择即可。
模型权重遵循各自许可证，不适用本程序许可证。

## 系统要求

- Windows 10 1903+ 或 Windows 11，x64
- 内存 8 GB 以上（模型约 1 GB）
- 显卡可选：有 Vulkan 支持的 GPU 会快 5–8 倍

## 已知限制

- 部分 Electron 应用不支持模拟复制，取不到选中文字；
  可先用 `Ctrl+C`，再用托盘菜单「翻译剪贴板」
- `Ctrl+P` 是多数软件的「打印」快捷键，全局注册会抢占它；
  可在「设置」里改成 `Ctrl+Alt+P` 等组合
